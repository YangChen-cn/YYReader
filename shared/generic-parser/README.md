# YYReader 通用小说解析器双端对齐说明

本文记录 macOS 通用解析器本轮增强，供 Windows 客户端实现等价规则。它不是新的同步协议，也不要求两端共用语言或解析库；目标是让相同网页在两端得到一致的书籍元数据、章节关系和干净正文。

## 处理顺序

两端建议保持以下顺序：

1. 获取最终 HTML；遇到 Cloudflare 或必须执行 JavaScript 的页面，完成用户验证后使用渲染后的 DOM。
2. 优先选择明确的正文容器，再考虑 `article` / `main`，最后才使用正文密度评分。
3. 从选中的正文容器拆分段落并执行导航、阅读设置、站点提示和水印清理。
4. 独立解析章节标题、书名、作者、目录、上一章、下一章和章节分页。
5. 目录页按 DOM 顺序生成章节，不按标题中的章节号重新排序。

## 正文容器

明确容器的当前优先集合：

```text
[itemprop=articleBody]
#content
#chaptercontent
#chapter-content
#nr1
.chapter-content
.read-content
.post-content
.entry-content
.content
```

存在多个候选时，使用“文本长度 - 2 × 链接文本长度 + 30 × 段落/换行数量”评分选择最高者。明确容器不足时再检查 `article, main`。如果页面已有至少 8 个形似章节标题的链接，却没有可靠正文容器，应优先把它当目录页，不能把长简介或目录列表当正文。

## 元数据

书名按以下信息择优：

1. `og:novel:book_name`
2. JSON-LD `isPartOf`
3. 书籍信息区、面包屑中的作品名
4. `og:title` 或页面 `<title>` 中的《书名》及“书名 + 第 N 章”结构

作者按以下信息择优：

1. `meta[name=author]`
2. `og:novel:author`
3. JSON-LD `author`
4. 作者链接、书籍信息区和 description 中的“某作者创作”结构

章节标题优先读取 `[itemprop=headline]`、站点常见标题节点和正文上方的章节型 `h1/h2`，并移除“第 N 页/共 N 页”等分页尾缀。不得把站点 Logo 当书名或章节标题。

## 章节导航

上一章和下一章按以下顺序解析：

1. `a[rel=prev]` / `a[rel=next]`
2. 链接文字精确匹配
3. 去掉空白后以前缀匹配“上一章、下一章、前一章、后一章”
4. 已知结构 `.prev_page a` / `.next_page_links a`

目录支持“目录、章节列表、返回目录、全部章节”以及明确的目录链接结构。章节正文分页单独识别“下一页、下页”，不得误当下一章。

书籍概览页可能只展示倒序的“最新章节”预览，再通过“全部章节、完整目录、查看全部章节”进入真正目录。刷新完整目录时，如果后续页面的章节集合完整包含前一页预览，并且章节数更多，应以完整页面替换预览，不能把倒序预览追加到目录开头。`序言` 与 `序章`、`后记` 一样属于有效章节标题。

章节链接内部如果包含 `h1...h6` 标题节点，应优先使用标题节点文本，不要直接采用整个链接的文本；后者可能把 `VIP`、`免费`、更新时间等状态标签拼进章节名。

用户主动“刷新目录”必须追踪全部目录分页或完整目录入口；“下载全部章节”必须先完成同样的全目录刷新，再基于刷新后的章节集合制定下载计划。初次导入仍可只取首个目录页，以缩短进入阅读所需时间。

## 正文清理规则

清理应针对完整段落，避免因为正文偶然出现关键词而误删。

### 导航段

以下形式整段删除：

```text
上一章 | 章节目录 | 下一章
上一章：某章节标题
下一章：某章节标题
```

实现要求：

- 如果段落移除“上一章、下一章、目录、上下页”等导航标签后只剩空白、标点或符号，删除整段。
- 如果段落符合 `^(上一章|下一章|上一章节|下一章节|前一章|后一章)[：:].+$`，删除整段。
- “故事里提到上一章留下的疑问”属于正常正文，必须保留。

### 反转码/阅读模式提示

部分站点使用斜杠拆字规避简单过滤，例如：

```text
如果被/浏/览/器/强/制进入……阅/读/模/式……请退出转/码阅读
```

匹配前仅用于检测地移除 `/`、`\` 和空白。如果同一段同时包含“浏览器”“阅读模式”“退出”“转码阅读”，删除整段。不要把去斜杠后的文本写回正文。

### 其他噪声

- 删除阅读设置，如字体大小、背景、护眼、关灯、繁简切换和直达底部。
- 删除“本站最新网址”“加入书签”“点击下一页继续阅读”等站点提示。
- 删除孤立水印；正文末尾附着的短站名水印只移除水印，不删除正文。

| `cn.wa01.com/novel/pagea/...` | 书名、目录元数据和结构型下一章 |
| `xiaoshuoxx.com/book/...` | 书名、作者、章节标题、正文分页；阅读设置不进正文 |
| `zuiaixs.net/read/...` | 长目录不得识别为正文；保留 DOM 章节顺序 |
| `luoxiadushu.com/...` | 书名、作者、章节导航、窄正文容器和水印清理 |
| `nitian.935666.xyz/...` | 删除带章节标题的上一章/下一章段和反转码提示 |
| `yeduji.com/book/...` | 从概览页进入“全部章节”；用完整正序目录替换倒序最新章节预览；全本下载前刷新目录 |

Windows 端完成对应升级时，至少为上述规则添加合成 HTML 单元测试。测试正文使用自造短段落，不保存第三方网站的完整版权内容，也不依赖实时网站。
