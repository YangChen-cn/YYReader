# Mac / iOS 更新

两端只使用 `YangChen-cn/YYReader` 的 GitHub Releases，不使用镜像或额外更新清单。自动检查默认开启，在启动及回到前台时触发；成功结果缓存 6 小时，使用 ETag 减少重复请求。设置里可关闭自动检查或立即手动检查。自动检查不弹窗、不下载，不打断阅读。

有新版本时，Mac 在左侧书架顶部单独显示“下载更新”入口，书籍列表自动往下排列；点击打开更新浮层，关闭后入口仍保留。iPhone / iPad 书架显示更新卡片，“暂时忽略”可收起卡片，保留小型更新图标；下一版本仍会提示。发布说明默认折叠，支持展开阅读及打开原始发布页面，也可在设置中手动检查并查看下载选项。

## macOS

1. 点击“下载更新”，显示进度条、百分比与下载大小，支持取消及失败后重试。
2. 下载至沙盒缓存，验证 GitHub 提供的 SHA-256 和文件大小。
3. 点击“安装并重启”后，独立的 `YYReaderUpdater.app` 只读挂载 DMG，检查 Bundle ID、版本、最低系统版本、arm64 与代码签名，并在原 App 同级目录暂存完整新版本。
4. 保存阅读进度，正常退出旧 App；退出失败则停止，不强制结束进程。
5. 替换 App，保留旧版备份直到新 App 成功启动；替换或启动失败时恢复原版本。成功后清理备份和本次下载。

主 App 继续使用现有 Sandbox 和权限。安装助手由 Launch Services 独立启动，不继承主 App 沙盒、不要求管理员权限、不注册常驻服务。它仅接受仍在运行的宿主与其自身所在的 App 路径，以及宿主沙盒更新缓存中的专用下载目录，不能通过参数清理任意文件夹。签名脚本先封装并签名助手，再签主 App。

运行在 DMG、App Translocation、临时 Debug 启动副本或不可写目录时，不覆盖其他 App；改为提示移动 App 或使用发布页手动安装。安装不会更换数据目录，也不会清理书架和阅读缓存。导入或离线下载未结束时暂不安装。

SHA-256 验证文件与 GitHub 元数据一致，代码签名验证包完整性；当前发布采用 ad-hoc 签名，校验不等于 Apple 公证或独立的发布者数字签名。可信来源仍依赖 GitHub 账户和 HTTPS。

## iOS / iPadOS

展示对应 iOS 发布说明，并提供 IPA 下载直达链接。侧载 App 无法自行覆盖安装自己，下载后继续由 SideStore、Sideloadly 等工具重新签名安装。

## 发布约定

- Mac 使用 `vX.Y.Z` 标签及 `YYReader-X.Y.Z-arm64.dmg`。
- iOS 使用 `ios-vX.Y.Z` 标签及 `YYReader-iOS-X.Y.Z-resign.ipa`。
- 只接受正式发布，忽略 Draft、Prerelease、Windows 安装包和非本仓库下载链接；按数字版本比较，不依赖全仓库的 Latest 标记。
- Mac 自动安装要求 Release asset 的 `digest` 含有效 `sha256:` 校验值；缺失时只提供发布页手动安装。
- 相同版本号重新上传不会触发升级，修复发布应递增版本号。
- 既有 1.4.0 安装包不含更新模块，需要先手动安装包含此功能的新版本，后续才可在应用内更新。

## 验收

Settings → 更新（Mac）或设置 → 软件更新（iOS）可检查状态、开关与最新版本提示。出现新版本后检查书架卡片、说明展开、Mac 下载取消/重试及安装重启；iOS 检查 IPA 链接。更新前后的书架和阅读位置应一致。

`AppUpdateTests` 使用本地构造数据覆盖版本与平台筛选、来源检查、校验、检查缓存和文件替换/回退；真实更新和界面由人工验收，不对用户现有安装执行自动测试。

## 临时 Debug 界面预览

使用 `--preview-update` 启动 Debug App，会显示标注为 UI 预览的 1.5.0 示例卡片；此版本号只是示意，没有发布。Mac 的“预览状态”可切换提示、下载中、完成及失败，也可点击下载按钮查看模拟进度与取消。iOS 的 IPA 按钮仅显示提示。所有预览动作都不会联网下载、替换 App 或重启。

```sh
./script/build_and_run.sh run --preview-update
xcrun simctl launch --terminate-running-process 当前模拟器UDID com.yyreader.ios --preview-update
```

点击 Mac 卡片右侧 ×、iPhone 的“暂时忽略”或“预览状态 → 退出预览”即可收起示例卡片，并停止模拟下载；书架更新入口和设置中的手动检查可重新显示示例，不写入正式版本的忽略记录。不带该参数重新启动即恢复正常检查。预览代码受 `#if DEBUG` 保护，Release 构建不包含预览入口及模拟逻辑。
