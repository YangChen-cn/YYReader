亮点

为长时间阅读做的取舍

不追功能数量，只把「读得下去」这件事做扎实：干净的正文、稳定的位置、随时可离线。

按内容导入

添加网址时可选自动识别 / 文字小说 / 漫画。选择随书籍保存，之后的加载、刷新目录与离线下载都沿用；旧书默认自动识别。

原生正文与排版

正文由原生控件渲染，不是网页套壳。主题、字体、字号、行距、段距、正文宽度与段首缩进都能调，支持 UTF-8 / GBK / GB18030 的 TXT。

连续阅读与预取

滚到章末自动接上下一章，默认预取小说 3 章、漫画 10 张图片；也可主动缓存当前章、后续章节或整本，断网照读。

论文伪装

一键把小说排成学术论文的样子：模拟标题、摘要、引用与图表，宽屏双栏、窄屏单栏。只改变呈现方式，不改写正文，切回来还在原位。

看得见的缓存

设置里能看到总占用与每本书占用，可按本或全部清理。漫画每本 512 MB 预算，超出后优先清理已读章节，当前章与未读内容始终保留。

跨设备接续

把任意共享文件夹（iCloud Drive、Dropbox、OneDrive、Syncthing、NAS）当作同步媒介，交换书架与阅读进度；正文与图片始终留在本机。

漫画

漫画也能放进同一个书架

同一套书架、缓存与进度机制，只是把「段落」换成「图片序列」。

专用适配

为常见站点写了针对性的解析，能拿到完整的图片列表，而不是只抓到首屏那几张：

  • 瓜子漫画
  • 再漫画
  • 好多漫
  • 漫画站
  • 多看漫画

通用识别

其他站点按正文区域、图片序列、尺寸与上下话导航综合打分识别；广告图集或证据不足时明确报错，不会把推荐位当成正文。

自动模式在小说正文不可信时尝试高置信度漫画解析；也可以在导入时手动指定为漫画。

翻页与缩放

左右翻页支持自动 / 单页 / 双页布局：横向大图独占，竖图成对，首图可单页，组合不跨章。iPhone 点击两侧切页、拖动跟手；双击放大后可捏合与拖动。

图片按需读取

部分站点用 blob: 呈现图片，YYReader 只读取页面上已经正常显示的那一张，绝不解密或绕过访问控制；解码与缓存都在后台完成。

缓存有预算

每本漫画 512 MB 预算，超出后按「最久没读」的顺序清理已读章节；当前章与还没读的内容不会被删掉。

站点适配细节与已知限制见 漫画阅读与适配说明。

跨设备接续

一个共享文件夹就够了

不架设服务器、不绑定账号。各端只写自己的快照文件，互相读取、无锁合并。

各端只写自己的快照并读取他端；书籍按规范来源 URL 合并，阅读位置只向更后推进。

  • 单向写入，天然免冲突

    每台设备只维护自己的文件，谁也覆盖不了谁，多端同时读也不会互相打架。

  • 位置只前进，不倒带

    合并时只接受更后的章节或同章更后的位置，避免设备时钟差异把进度顶回去。

  • 离线也不清书架

    共享目录暂时不可用或快照损坏时，保留本机书架与缓存，恢复后继续合并。

  • 正文不出设备

    快照只含书名、来源与进度索引，不含正文、漫画图片、Cookie 或登录信息。

常见问题

你可能想知道的

支持哪些小说网站？

专门的适配覆盖 qidiy.com 等站点；其余大多数站点由通用解析引擎处理：按 JSON-LD、OpenGraph、正文语义容器与中文标点密度判断正文，只要能正常显示章节正文和上一章 / 下一章导航，通常都能解析。

遇到 Cloudflare 验证怎么办？

应用优先用轻量的原生请求抓静态页面；若站点要求人机验证或必须执行脚本，会打开一个可交互的浏览器窗口让你完成一次验证，之后把渲染结果交回原生阅读器。正文不会在浏览器里阅读，也不会自动尝试绕过验证码、登录或付费墙。

漫画支持哪些站点？

瓜子漫画、再漫画、好多漫、漫画站、多看漫画有专用适配；其他站点通过正文区域、图片序列与导航综合识别，证据不足时会明确提示失败，而不是抓一堆广告图。细节见漫画阅读与适配说明。

iPhone / iPad 版本怎么安装？

下载 IPA 后用 SideStore、Sideloadly 等工具用自己的 Apple ID 签名安装，7 天有效期由工具负责续签。作者已完成过真机签名、阅读与同步的完整流程；具体步骤见iOS 开发与安装说明。

同步会上传正文吗？需要联网吗？

不会。同步只交换书架、书籍信息与进度索引，正文与漫画图片始终留在本机。同步也不需要常连网络：离线时进度先存在本地，共享文件夹恢复可用后自动合并。

Windows 版为什么没有漫画？

漫画支持目前在 Mac 与 iOS 端提供（含双页布局、图片缓存预算与专用站点适配）。Windows 1.3.0 专注于小说阅读、TXT 导入、离线缓存、论文伪装与书架同步。

论文伪装模式会改写正文吗？

不会。它只改变呈现方式：套上模拟的论文标题、摘要、引用与图表，宽屏双栏、窄屏单栏。切回普通阅读后仍在原来的位置，正文内容一字不改。
